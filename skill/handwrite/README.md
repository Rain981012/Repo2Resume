# 手写脚手架（Phase A1）

按 `MVP_PLAN.md` **【手写】脚手架教练**：`SKILL.md` 与四组 prompts 须亲手完成。

## SKILL 对照

| 文件 | 用途 |
|---|---|
| `SKILL.md` | **已定稿**（并已同步到 `../SKILL.md` 供 Cursor 加载） |
| `SKILL.scaffold.md` | 旧脚手架（若还在，仅作历史对照） |
| `SKILL.complete.example.md` | 完整示例（若还在） |

## Prompts 手写（当前任务）

| 文件 | 对应 Step | 状态 |
|---|---|---|
| `prompts/01_skill_profile.md` | Step 2 画像 | 脚手架 → 你填 |
| `prompts/02_job_search.md` | Step 3 搜岗打分 | 脚手架 → 你填 |
| `prompts/03_resume_writing.md` | Step 4 写作 | 脚手架 → 你填 |
| `prompts/04_critic_review.md` | Step 4 审稿 | 脚手架 → 你填 |

建议顺序：**01 → 04 → 03 → 02**（先定画像与审稿标准，再写作与搜岗），或严格按 Step **01 → 02 → 03 → 04**。

定稿后拷贝到 `skill/prompts/`（覆盖或替换早期 AI 稿），保证与 `skill/SKILL.md` 链接一致。

卡住时对 AI 说：「按脚手架教练看 01，先提示思路」或「给我 complete 示例但附理解题」。
