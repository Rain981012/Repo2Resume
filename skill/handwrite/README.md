# 手写脚手架（Phase A1）

按 `MVP_PLAN.md` **【手写】脚手架教练**：本目录只有结构与待填空，**禁止直接复制** `../SKILL.md` 或 `../prompts/` 的 AI 成品当终稿。

## 怎么用

1. 在本目录填空，写到你满意。
2. 自检通过后，把终稿**覆盖/拷贝**到 `skill/SKILL.md` 与 `skill/prompts/`（宿主 skill 实际加载的是那一层；`.cursor/skills/repo2resume` 链到 `skill/`）。
3. 卡住时对 AI 说：「卡死了，先提示思路」或「看参考版并附理解题」——仍不要让 AI 整块代写。
